# GATC Restaurant Operations — Marketing Website

Selected design: Option 1 (Editorial).

## Contents
- `index.html` — self-contained responsive marketing landing page (HTML, CSS, and small navigation script).

## Preview
Open `index.html` in a browser. The site is static and requires no build step.

## Publishing
Upload `index.html` to the root of your **separate marketing website** GitHub repository. Review changes before committing or deploying. Depending on your hosting provider, you may need to configure a deployment from that repository.

**Do not** upload these files to the George's at the Cove application repository.

## Domain and email safety
This package makes no DNS changes. Keep existing Squarespace DNS and Google Workspace MX, SPF, DKIM, and DMARC records intact. Connecting `gatcapp.com` to a web host is a separate step and must be planned around the existing mail configuration.

## Before going live
- Confirm that the proposed $149/month per-location pricing is what you want to advertise.
- Verify `joe@gatcapp.com` can receive demo requests.
- Test the website on mobile and desktop browsers.
- Verify the hosting provider's required domain configuration before changing any DNS records.

This package is not a deployment and does not modify GitHub, Squarespace, Render, or Google Workspace.
